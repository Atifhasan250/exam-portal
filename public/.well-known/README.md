# Digital Asset Links

`assetlinks.json` is intentionally committed with a placeholder fingerprint so the path deploys before the Android signing key is finalized.

Before expecting Trusted Web Activity verification to pass, replace `REPLACE_WITH_RELEASE_OR_PLAY_SIGNING_SHA256_FINGERPRINT` with the SHA-256 fingerprint for the APK/AAB signing certificate. If Google Play App Signing is enabled later, use the Play App Signing certificate fingerprint from Play Console.
